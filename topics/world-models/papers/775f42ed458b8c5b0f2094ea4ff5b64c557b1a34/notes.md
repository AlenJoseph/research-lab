# Paper notes — AMI (LeCun)

## Summary

Position paper: path to **Autonomous Machine Intelligence** via modular architectures—world models, JEPA, hierarchical planning—not scaling autoregressive token prediction alone.

## Key claims

- Current LLM path is a **subset** of intelligence; lacks grounded world modeling
- JEPA predicts in representation space—**abstraction** over raw sensory prediction
- Advocates self-supervised predictive learning + modular cognitive architecture

## Methods / equations

- Conceptual framework—not a single benchmark paper

## Relevance to our problem/gap

- **Motivation anchor** for intuition vs exhaustive context thesis
- Gap identified here is not empirically closed in follow-on JEPA work (composition + FLOPs)

## Limitations

- Manifesto; empirical gaps remain open (our survey confirms)
